# Starmonia (versión web)

Esta carpeta es lo que publica Netlify. Cada vez que se sube un cambio acá, el sitio se actualiza solo.

- `index.html`: la app completa.
- `iconos/`: íconos y logo.
- `_headers`: permite que la separación con IA use varios núcleos del procesador.
- `netlify.toml`: le dice a Netlify que publique esta carpeta tal cual, sin compilar nada.
